# Code of Conduct

## Our Standards

Contributors must help maintain a respectful, constructive, and harassment-free
community. Examples of positive behavior include giving useful feedback,
respecting different viewpoints, accepting responsibility, and focusing on what
is best for the project and its users.

Unacceptable behavior includes harassment, discrimination, insults, threats,
publishing private information without permission, or disrupting project
discussions.

## Enforcement

Report unacceptable behavior privately through the GitHub private-reporting
link in [SECURITY.md](SECURITY.md), using a title that begins with "Conduct:".
Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when conduct violates these standards.

Reports will be reviewed fairly and kept confidential when possible.
